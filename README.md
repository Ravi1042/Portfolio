# Ravisankar Chengannagari — Business Analyst Portfolio

This is a self-contained static portfolio website. The full HTML, CSS, and JavaScript are included in `index.html`.

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for a personal site, name it `<your-username>.github.io`).
2. Upload `index.html` to the repository root and commit the changes.
3. Open **Settings → Pages** in the repository.
4. Under the build/deployment source, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
5. Wait for the deployment to finish and open the URL shown in the Pages settings.

GitHub Pages serves static HTML, CSS, and JavaScript, so the website's inline styles and client-side animations are compatible. It does not run server-side code. See the official [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
